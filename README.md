# intermediatecs-shell-scripting
Shell scripting activity for students

## Instructions

### Part A
1. Fork this repository by clicking the Fork icon in the top-right corner
1. Clone this repository to your computer so that you can edit it locally
1. Make a shell script file with your name as the title, and a .sh extension
1. Write your name, your grade, and your favorite flavor of ice cream. Have it print using a series of "echo" commands.
1. Run the script in your Terminal to test it.
1. Commit this script to your local repository.
1. Push this script to your Github (remote) repository.
1. Submit your repository's URL to Google Classroom!
