# intermediatecs-shell-scripting
Shell scripting activity for students

## Instructions
1. Fork this repository by clicking the Fork icon in the top-right corner
1. Clone this repository to your computer so that you can edit it locally
1. Write a series of commands that: 
  a. Asks for the user's name, and saves that to a variable. 
  b. Ask the user to enter their favorite flavor of ice cream, and saves that to another variable 
  c. Using the say command in the non default voice, has the CLI welcome the user to the program and react to the flavor input.
1. Save these commands as a script. Save the file, call it `shellscript.sh` and make the file executable. 
1. Commit this script to your local repository.
1. Push this script to your Github (remote) repository.
1. Submit your repository's URL to Google Classroom! All Done!
